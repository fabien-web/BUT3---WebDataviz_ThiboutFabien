# Dashboard Zelda – Fabien Thibout

## Présentation
Projet de datavisualisation réalisé avec **Power BI** dans le cadre du BUT3 WebDataViz.

**Objectif :** comparer les performances commerciales et la réception critique des jeux *The Legend of Zelda* face aux meilleures ventes de Nintendo Switch.

## Contenu du dossier

- `Dashboard_FabienThibout.pbix` : tableau de bord interactif réalisé avec Power BI.
- `Dashboard_FabienThibout.png` : capture du tableau de bord final.
- `FOND_POWER_BI.png` : fond graphique personnalisé inspiré de l'univers Zelda.
- `DONNEES_NINTENDO_ZELDA.csv` : jeu de données utilisé pour les visualisations.

## Sources des données (récoltées 'manuellement')

- **Nintendo IR** : ventes cumulées des jeux Nintendo Switch (au 30/06/2026).
- **Metacritic** : notes attribuées par la critique aux différents jeux.

## Visualisations réalisées

1. Classement des 10 meilleures ventes Nintendo Switch.
2. Comparaison du rythme moyen des ventes par an.
3. Analyse de la relation entre ventes commerciales et Metascore.
4. Synthèse des performances de Zelda face aux autres franchises Nintendo.

## Outils utilisés
**Power BI Desktop**, CSV, GitHub.
